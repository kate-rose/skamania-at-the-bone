# Skamania at the Bone

A visual briefing for the 17th Legislative District's representatives-elect on Skamania County's 2027 budget gap, why it is structural, and the state levers that could help. Prepared by the [Skamania Dispatch](https://skamaniadispatch.com) from public records in the Open Gorge Public Meetings Archive.

Read it at https://kate-rose.github.io/skamania-at-the-bone/ or download the [PDF](Skamania-at-the-Bone_LD17-briefing.pdf).
